# Codex native question evidence

Schema files were generated by the installed `codex-cli 0.161.0` with
`codex app-server generate-json-schema --experimental`.

The `*.live.json` frames were captured from that binary on 2026-10-27 in an
ephemeral, read-only Plan mode conversation. The agent asked two questions;
the client answered by native IDs (`placement`, `layout`) and the real agent
completed with `Activity\nCompact`. No credentials, project files or private
prompts are included.

These verify the wire mapping only. The backend tests additionally replay the
frames through the production reader/dispatch path and cover request recovery,
retraction, duplicate submissions and write failures.

The `*.default-mode.live.json` pair repeats the real two-question round-trip
without collaborationMode/Plan. Only the subprocess config override
`-c features.default_mode_request_user_input=true` was added; the CLI's own
`features list` reported this switch as disabled before the subprocess override. The real model
again completed with the chosen labels. ACPCore adds this subprocess-only
override on both initial spawn and wake, leaving global CLI config untouched.
